# Asset manifest

Everything in the film is generated by the code in this folder, except the files listed here.

| Asset | Source | Licence | Where |
|---|---|---|---|
| Human base mesh (`base.obj`), shape targets, default skeleton + weights, 60 face pose units | MakeHuman 1.x system assets (makehumancommunity/makehuman, `makehuman/data`) | CC0 1.0 | `assets/makehuman/` (exact files, sizes and SHA-256 in `assets/makehuman/MANIFEST.json`; licence text in `assets/LICENSE.ASSETS.md`) |
| Subtitle font | Liberation Serif (system font, used by ffmpeg/libass at encode time, not shipped) | SIL OFL 1.1 | not in the repo |

Generated by code (no external media): every texture and shader (procedural), hair/brows/beard/fur geometry,
clothing (cut from the MakeHuman fitting helpers), the village (ground, trees, huts, fires, props), sky, mist and
smoke, all animation, cameras and lights, and every sound (ambience, birds, fire, footsteps, cloth, breath,
whispers, score), synthesised in `audio/sound_design.py`.

Voices, when recorded, come from ElevenLabs (voice design, so no real person's voice is cloned) under the account's
commercial licence, generated by `tools/elevenlabs-assets.cjs`.

Reference videos sent by the owner were used only to discuss pacing and style; nothing from them (images, sound,
characters) is used or copied.
